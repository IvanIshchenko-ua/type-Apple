# Apple-Inspired Minimalist Website

An elegant and minimalist website inspired by Apple's design philosophy, featuring clean lines, neutral colors, and smooth animations.

## Features

- **Clean Design**: Neutral color palette (white, black, gray) with elegant gradients
- **Large Typography**: Bold, eye-catching headings with proper letter-spacing
- **Smooth Animations**: CSS keyframe animations and smooth transitions
- **Interactive Elements**: Hover effects, ripple animations, and visual feedback
- **Responsive Design**: Mobile-first approach with hamburger menu for small screens
- **Accessibility**: Semantic HTML, proper focus states, and ARIA-friendly
- **Performance Optimized**: RequestAnimationFrame for scroll effects, Intersection Observer for lazy animations

## Quick Start

Simply open `index.html` in your web browser:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx http-server -p 8080

# Or just open the file
open index.html
```

Then navigate to `http://localhost:8080` in your browser.

## Design Principles

This website follows Apple's design philosophy:

1. **Simplicity**: Clean, uncluttered interface
2. **Functionality**: Every element serves a purpose
3. **Beauty**: Attention to detail in typography and spacing
4. **Innovation**: Modern web technologies and smooth interactions
